
#  Windows 10 Installation for Campus Students

##  Project Overview

This project documents the process of installing Windows 10 Education on campus computers using a bootable USB drive.

I created a 34-page, step-by-step installation guide with photographs to help students complete the installation process in a classroom environment.

The guide covers preparing the computer, replacing removable drives, booting from USB, installing Windows, configuring user accounts, and completing the final setup.

##  Tools & Technologies

- Windows 10 Education
- Bootable USB Installation Media
- Dell Desktop Computers
- BIOS / Boot Process
- Hard Drive Installation
- Windows Setup and Configuration

##  Tasks Documented

1. Removed the classroom's resident drive and installed a student drive.
2. Connected a bootable Windows 10 USB drive.
3. Started the computer and accessed the Windows installation process.
4. Selected Windows 10 Education.
5. Managed disk partitions and selected the installation drive.
6. Installed Windows 10 and completed the restart process.
7. Configured region, keyboard, and user account settings.
8. Created a password and security questions.
9. Configured Windows privacy settings.
10. Verified the installation and shut down the computer.
11. Removed the installation USB and restored the classroom drive.
