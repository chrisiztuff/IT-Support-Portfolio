# Active Directory Domain Networking Lab

## Project Overview
This project documents my hands-on experience with Active Directory domain networking through a CompTIA CertMaster guided lab. The lab focused on Windows domain administration, network troubleshooting, user account management, Group Policy, and file permissions.

## Lab Environment
- Windows Server
- Windows client workstation
- Active Directory Domain Services (AD DS)
- PowerShell
- Group Policy Management
